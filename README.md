# Soniya Sadasivam – Portfolio
Pure HTML, CSS and vanilla JS. No build step.
## Run
VS Code → install **Live Server** → open the `portfolio` folder → right-click `index.html` → *Open with Live Server*.
## Customise
- **Email / LinkedIn**: search `your-email@example.com` and `data-todo="LinkedIn URL"` (href="#") across all four HTML files.
- **Screenshots**: put images in `assets/projects/`, then replace a `<div class="ph">…</div>` with `<img src="assets/projects/yourfile.png" alt="describe it">`. In the gallery, put the `<img>` inside the same `<figure>` (the lightbox picks it up).
- **Projects / gallery**: edit the titles, descriptions, tech chips and `#` links in `development.html` and `design.html`.
- **SauceDemo section**: fill in the italic *Add…* prompts in `testing.html` using your real results only.
- **Colours**: edit the four variables at the top of `css/style.css`.
